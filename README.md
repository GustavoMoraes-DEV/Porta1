## 📌 Objetivo do Projeto

Este projeto foi desenvolvido utilizando ESP32, MicroPython, display OLED e servo motor para simular um sistema de controle de acesso. Através de botões, o usuário pode interagir com o sistema, visualizar mensagens no display e controlar a posição de um servo motor responsável pelo mecanismo de bloqueio e desbloqueio.

## 🎯 Funcionalidades

- Exibição de mensagens em um display OLED.
- Controle de LEDs para indicar estados do sistema.
- Acionamento de um servo motor.
- Leitura de múltiplos botões utilizando entradas digitais.
- Simulação de um sistema de acesso bloqueado/desbloqueado.

## 📚 Aprendizados

Durante o desenvolvimento deste projeto foram praticados os seguintes conceitos:

- Programação em Python (MicroPython).
- Comunicação I2C com display OLED SSD1306.
- Controle de servo motor utilizando PWM.
- Manipulação de GPIOs como entrada e saída.
- Utilização de resistores Pull-Up internos.
- Estruturas condicionais (`if`).
- Criação de funções para reutilização de código.
- Desenvolvimento de sistemas embarcados com ESP32.
